# SSH Brute Force Case Study

This scenario demonstrates the full SOC workflow for detecting and investigating SSH brute force activity.

Steps covered:

1. Simulated brute force attack from a Kali Linux VM
2. Alert generation in Wazuh SIEM
3. SOC-style investigation of authentication logs
4. Development of a detection use case

## Artifacts

| Artifact | Description |
|--------|--------|
| Investigation | SOC-style analysis of the alert |
| Detection Use Case | SIEM rule logic and detection design |
